# Jeminise Shopify Theme

Shopify theme built with Dawn as the base template (Online Store 2.0).

## Development

Run development server with Shopify CLI:

```bash
shopify theme dev --store=your-store.myshopify.com
```

## Pull / Push changes

- Push to live theme:
  ```bash
  shopify theme push --store=your-store.myshopify.com
  ```

- Pull remote theme settings:
  ```bash
  shopify theme pull --store=your-store.myshopify.com
  ```
